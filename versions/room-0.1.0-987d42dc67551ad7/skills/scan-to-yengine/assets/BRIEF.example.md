# Example reconstruction brief (fictional)

Room ID: `my-room`
Revision: `measured-layout-1`
Inputs: `output/room/inputs/my-room/` (user-provided iPhone export)
Output: `<my-room-project>/src/` (R3F by default; Three `build()` is optional)
Project inputs: `room.project.json` parameters/state and declared `assets/` files
Build identity: generated by `room build`; record it with comparison evidence

## Evidence

Record the selected room index, scan frame, floor height and transforms after inspecting the export. Do not substitute example dimensions for measurements.

## Architecture

List measured walls, openings and ceiling changes. Record whether each feature is captured or inferred.

## Furniture and details

For each area: list stable object IDs, relevant photo indices, measured bounds, materials and unresolved questions. Build large shapes first, then refine the details needed for the requested fidelity.

## Verification

Record matched-camera comparison paths, observed discrepancies, fixes and remaining uncertainty. Check alternate views and a production build before delivery.

When physics is requested, record collision approximations and fixed-step contact/opening results. Label synthetic fixtures. Assign separate part/item files when splitting work.
